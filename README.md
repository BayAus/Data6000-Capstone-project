# Capstone-project-Traffic accident severity prediction

# Overview

This project focuses on solving a real-world business problem using data analytics, ML, and data visualization techniques. 
The objective of this project was to predict the severity of road accidents and provide insights to support faster, better-informed responses by emergency services.

# Business Problem

Road transport industry is a crucial part of country’s economy and people’s daily life, but we face persistent 
challenges in ensuring road safety. There are thousands of accidents annually, resulting in serious injuries, 
fatalities and financial hardships. 

# Dataset

Data source: https://data.sa.gov.au/data/dataset/road-crash-data
https://www.aihw.gov.au/reports/injury/transport-accidents

Time period covered: 2019–2023
